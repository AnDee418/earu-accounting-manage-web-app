振り分けルール

- 伝票日付はYYYYMMDD形

- 借方/貸方　消費税額は空欄 ※税計算モードを内税計算に設定しているため

- 借方/貸方　金額は税込金額

- 入力プログラム区分は「2」固定

- 摘要のルール=>[○○代　ABC株式会社] ※駐車場代などが入る、後ろに取引先の会社名
