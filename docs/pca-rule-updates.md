# PCA ルール仕様対応アップデート

## 概要
PCA会計ソフトの仕様に完全準拠するため、ルール適用エンジンとテスターフォームを更新しました。

## 主な変更点

### 1. 勘定科目マスター（PCA仕様準拠）
```
724: 福利厚生費
726: 旅費交通費
727: 通信費
729: 車両費
731: 運賃
733: 交際接待費
734: 会議費
737: 消耗品費
738: 租税公課
754: 事務用消耗品費
111: 現金（貸方固定）
```

### 2. 部門・現金補助科目マッピング
```
1: 札幌支店 → 現金補助科目 001
2: 仙台事業所 → 現金補助科目 002
3: 東京支店 → 現金補助科目 003
4: 福岡事業所 → 現金補助科目 004
5: 大阪事業所 → 現金補助科目 005
6: 名古屋事務所 → 現金補助科目 006
```

### 3. 税区分コード（PCA仕様）
```
00: 対象外（現金・貸方固定）
P0: 非仕入（租税公課専用）
Q5: 仕入10%（10%インボイス対応）
Q6: 仕入8%軽（8%インボイス対応）
QD: 仕入10%控80（10%インボイス非対応）
QE: 仕入8%軽控80（8%インボイス非対応）
```

### 4. 摘要フォーマット
- **新形式**: `[○○代　ABC株式会社]`
- **例**: `[旅費交通費代　JR東日本]`
- 全角スペース「　」を使用

### 5. PCA出力仕様
- **伝票日付**: YYYYMMDD形式
- **入力プログラム区分**: 「2」固定
- **消費税額**: 空欄（内税計算モード）
- **金額**: 税込金額
- **税計算モード**: 租税公課=0、現金=0、その他=1

## テスターフォーム更新

### プリセットテストシナリオ追加
1. **旅費交通費**: JR東日本、10%インボイス対応
2. **車両費（インボイス有）**: エネオス、10%インボイス対応
3. **車両費（インボイス無）**: 個人商店、10%インボイス非対応
4. **租税公課**: 市役所、0%非課税

### フォーム項目更新
- 勘定科目選択肢をPCA仕様に更新
- 部門選択肢を6部門に拡張
- 税額入力フィールド追加
- PCA形式の摘要ヘルプテキスト追加

### 結果表示改善
- PCA出力形式での詳細表示
- 借方・貸方の明確な分離
- 補助科目情報の表示
- 税区分名称の表示

## 技術的変更

### RuleApplicationEngine
- `generateDescription()`: PCA形式対応
- `getAccountName()`: PCA勘定科目マスター対応
- `getSubAccountName()`: 複数補助科目タイプ対応
- `validateDescriptionFormat()`: PCA形式検証

### データ型定義
- `DEFAULT_DEPARTMENT_MAPPINGS`: 6部門対応
- `DEFAULT_DATA_FORMAT_SETTINGS`: PCA摘要テンプレート

### テスト更新
- 全21テストケースをPCA仕様に更新
- 新しい摘要フォーマット対応
- 部門名称変更対応
